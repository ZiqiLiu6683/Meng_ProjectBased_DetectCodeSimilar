Design profile
Engineering-platform review deck. Premium but restrained, with editorial claims, technical diagrams, and dense but readable proof objects.

Usage
Use paper background for narrative and review slides, ink background for chapter/architecture slides. Use blue for pipeline structure, green for evidence/support, amber for limitations or next-step emphasis, red sparingly for risk. Avoid a one-hue dashboard look.

Chart and diagram grammar
Use editable rectangles, rules, and direct labels. Avoid legends where labels can attach directly. Use thin rules and lane labels. Stages are shown as numbered blocks or horizontal rails. Evidence flow diagrams use left-to-right reading.

Container grammar
Use boxes only for real grouping: strategies, stages, limitations, roadmap phases. No nested cards. Radius is minimal through square rectangles.

Footer grammar
Small section marker at bottom left and page number at bottom right.

Layout families
Cover with stage rail, spectrum map, strategy matrix, split proof comparison, architecture rail, flow diagram, product UI journey, limitation map, roadmap, closing synthesis.

Banned motifs
No decorative gradient orbs, no pseudo logos, no stock imagery, no generic SaaS card grid.
